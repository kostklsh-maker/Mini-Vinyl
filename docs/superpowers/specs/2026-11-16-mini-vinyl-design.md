# Mini-Vinyl — проект NFC-проигрывателя на ESP32

Дата: 2026-11-16. Статус: проект на утверждении.

## 1. Что это и зачем

Настольный мини-проигрыватель. Кладёте NFC-пластинку Ø50 мм в гнездо — вокруг неё
по часовой стрелке «бежит» свет (эффект вращения), из встроенного динамика играет
трек с карты памяти. Снимаете пластинку — свет плавно «останавливается», музыка
встаёт на паузу. Телефон, интернет и приложения не нужны.

Пластинки уже есть: ламинированные NFC-метки на пластике, останется наклеить обложки.

## 2. Цели и не-цели

**Цели**
- Автономная работа: MP3 на microSD внутри корпуса.
- Пластинка определяется по заводскому номеру чипа (UID). В метки ничего не пишем.
- Эффект вращения светом, без движущихся частей.
- Корпус печатается на Bambu A1: сопло 0,4 мм, слой 0,20 мм, PLA, без AMS,
  посадочный зазор 0,15 мм (как в Findypet).
- Новая пластинка добавляется правкой одного текстового файла на карте.

**Не-цели (в первую версию не входят)**
- Мотор и реальное вращение.
- Bluetooth, Wi-Fi, стриминг, приложение.
- Экран.
- Аккумулятор: питание от USB-C. Место под аккумулятор в корпусе оставляем (раздел 10).

**Что считаем провалом, даже если «работает»**
- Пластинка читается через раз или только в одном положении.
- Щелчки/треск в динамике от считывателя или светодиодов.
- Свет «шагает» по диодам рывками вместо плавного перетекания.

## 3. Рассмотренные подходы

| Подход | Плюсы | Минусы | Решение |
|---|---|---|---|
| Мотор N20 + пассик, пластинка реально крутится | настоящий винил | механика, шум редуктора рядом с динамиком, металл у антенны | отклонён автором |
| **Светодиодное кольцо вокруг пластинки, «бегущий» свет** | нет механики и шума, проще корпус, красиво в темноте | медь кольца рядом с антенной NFC — надо проверить на столе | **выбран** |
| Подсветка под прозрачной пластинкой | эффектно | пластинка непрозрачная, кольцо легло бы прямо на катушку метки | отклонён |

Музыка: свои MP3 на microSD (выбор автора). Стриминг и «Bluetooth-колонка + телефон»
отклонены: первое зависит от сети и подписок, второе не даёт эффекта «пластинка сама играет».

## 4. Что известно о пластинке

- Диаметр диска Ø50 мм.
- Катушка метки — кольцо, по фото внешний диаметр ≈ 35 мм, внутренний ≈ 22 мм,
  **соосна диску**. Чип — на внутреннем краю катушки.
- Раз катушка по центру, пластинку можно класть в гнездо в любом повороте — связь
  с антенной одинаковая.
- Тип чипа не проверен (вероятно NTAG213/215). Для проекта важен только UID,
  он читается у любых меток 13,56 МГц ISO 14443A, в том числе заблокированных.
- Толщина диска не измерена. В проекте принята до 1,0 мм (глубина гнезда 1,2 мм) — уточнить штангенциркулем.

## 5. Электроника

### 5.1. Список деталей

| № | Деталь | Точное название для поиска | Кол-во | ≈ цена |
|---|---|---|---|---|
| 1 | Контроллер | ESP32 DevKit V1, ESP32-WROOM-32, 30 pin, USB-C | 1 | 4 $ |
| 2 | Считыватель NFC | PN532 NFC module V3 (красная плата ≈ 43×41 мм) | 1 | 3–4 $ |
| 3 | Усилитель | MAX98357A I2S 3W amplifier | 1 | 1,5 $ |
| 4 | Динамик | Ø40 мм, 4 Ом, 3 Вт | 1 | 1,5 $ |
| 5 | Карта памяти | модуль microSD SPI **на 3,3 В** (маленький, без стабилизатора) + карта ≤ 32 ГБ, FAT32 | 1 | 1 $ + карта |
| 6 | Подсветка | WS2812B ring 24 LED (внешний Ø ≈ 66 мм, внутренний ≈ 52 мм) | 1 | 2,5 $ |
| 7 | Ручка | энкодер EC11 с кнопкой, вал 15–20 мм | 1 | 0,5 $ |
| 8 | Мелочь | конденсатор 1000 мкФ 10 В, резистор 330 Ом, провод 26–28 AWG, 4 винта M3×8, 4 силиконовые ножки | — | 2 $ |

Итого ≈ 15–18 $ без карты памяти.

Почему так:
- **PN532, а не RC522**: увереннее читает наклейки NTAG через пластик, работает по I2C (2 провода).
- **Обычный ESP32 без PSRAM** достаточен: MP3 декодирует библиотека ESP8266Audio.
- **Кольцо 24 диода** — единственный ходовой размер, внутрь которого помещается диск Ø50.
  Размеры колец у продавцов гуляют на 1–2 мм: измерить своё до печати.

### 5.2. Схема подключения

| Модуль | Контакт модуля | ESP32 |
|---|---|---|
| PN532 (I2C) | SDA | GPIO 21 |
| | SCL | GPIO 22 |
| | IRQ | GPIO 32 |
| | RSTO/RST | GPIO 33 |
| | VCC / GND | 3V3 / GND |
| microSD (SPI) | CS | GPIO 5 |
| | SCK | GPIO 18 |
| | MOSI | GPIO 23 |
| | MISO | GPIO 19 |
| | VCC / GND | 3V3 / GND |
| MAX98357A | BCLK | GPIO 26 |
| | LRC | GPIO 25 |
| | DIN | GPIO 27 |
| | Vin / GND | VIN (5 В) / GND |
| | + / − | динамик |
| WS2812B ring | DI | GPIO 13 через резистор 330 Ом |
| | 5V / GND | VIN (5 В) / GND, рядом конденсатор 1000 мкФ |
| Энкодер EC11 | A / B | GPIO 16 / GPIO 17 |
| | SW | GPIO 14 |
| | общий | GND |

Примечания:
- На PN532 переключатели режима поставить в I2C: **SEL0 = ON, SEL1 = OFF**.
- 5 В для усилителя и кольца берём с вывода VIN платы ESP32 (это шина USB).
- Яркость кольца ограничена в прошивке (≈ 20 %), общий ток устройства ≈ 0,4–0,6 А —
  хватает любого зарядника от телефона.
- Если кольцо мерцает от сигнала 3,3 В — добавить преобразователь уровня 74AHCT125.
  В большинстве случаев не требуется.
- Провода динамика и антенну PN532 держать подальше друг от друга.

### 5.3. Линейный выход AUX 3,5 мм

Выход усилителя MAX98357A на AUX подавать нельзя: это мостовой выход на динамик, он не привязан к земле.
Поэтому добавляется отдельный ЦАП **PCM5102A (плата GY-PCM5102)** с гнездом 3,5 мм на борту. Он подключается
параллельно усилителю к тем же трём проводам звука, выход стерео.

| Модуль | Контакт | ESP32 |
|---|---|---|
| PCM5102A | BCK | GPIO 26 (вместе с BCLK усилителя) |
| | LCK | GPIO 25 (вместе с LRC) |
| | DIN | GPIO 27 (вместе с DIN) |
| | SCK | GND (перемычка на плате) |
| | VIN / GND | VIN (5 В) / GND |
| MAX98357A | SD | GPIO 4 |

- Перемычки на обратной стороне GY-PCM5102: H1L, H2L, H4L — в положение L, H3L — в положение H.
  На части плат они уже запаяны, проверить по фото.
- **Переключение «динамик / AUX»**: долгое нажатие ручки, выбор запоминается. В режиме AUX прошивка
  прижимает вывод SD усилителя к земле (динамик молчит); в режиме динамика вывод отпущен.
- Громкость ручкой действует и на AUX.
- Корпус: плата ЦАП ставится гнездом к задней стенке рядом с USB-C, в стенке отверстие Ø6,5 мм.
- Если во внешней колонке слышен фон, когда она питается от того же зарядника, — помогает
  отдельный блок питания колонки или развязка «ground loop isolator 3.5 mm».

## 6. Прошивка

Среда: Arduino IDE или PlatformIO, ядро ESP32. Библиотеки: Adafruit PN532,
ESP8266Audio, FastLED.

### 6.1. Карта памяти

```
/tags.csv
/music/queen/01.mp3
/music/queen/02.mp3
/music/single.mp3
```

`tags.csv` — по строке на пластинку: `UID;путь;цвет`

```
04A1B2C3D4E580;/music/queen;FF6A00
04112233445566;/music/single.mp3;00B4FF
```

- Путь — файл (один трек) или папка (альбом, файлы играют по имени по порядку).
- Цвет — необязательный, цвет бегущего света для этой пластинки (по умолчанию тёплый белый).
- MP3: 44,1 кГц, 128–320 кбит/с. Большие обложки внутри файлов лучше убрать — трек стартует быстрее.

### 6.2. Поведение

| Состояние | Свет | Звук |
|---|---|---|
| Ожидание, пластинки нет | медленное «дыхание» всего кольца | тишина |
| Пластинка найдена в `tags.csv` | свет разгоняется до 33⅓ об/мин (оборот за 1,8 с), по часовой стрелке | играет трек/альбом |
| Пластинку сняли | свет плавно замедляется и гаснет, как останавливается винил | пауза |
| Ту же пластинку вернули | разгон | продолжение с места паузы |
| Положили другую | разгон, новый цвет | новый трек с начала |
| Трек/альбом кончился | замедление, затем «дыхание» | тишина |
| Незнакомая пластинка | три красные вспышки | тишина |

- **Плавность**: «комета» из яркой головы и хвоста на ~8 диодов, положение считается
  дробно между диодами, 60 кадров/с, гамма-коррекция. Так свет перетекает, а не шагает.
- **Опрос метки**: раз в 0,5 с. «Сняли» — после двух пропусков подряд (≈ 1 с),
  чтобы случайный сбой чтения не обрывал музыку.
- **Незнакомая пластинка**: её UID дописывается в `/unknown.txt` на карте и печатается
  в порт. Вы копируете номер в `tags.csv` — и пластинка заведена. Отдельная программа
  для чтения номеров не нужна.
- **Ручка**: поворот — громкость (запоминается), нажатие — пауза/продолжить,
  двойное нажатие — следующий трек альбома.
- Wi-Fi и Bluetooth выключены (меньше потребление и помех).

## 7. Корпус

Форма — мини-вертушка: слева «диск» со световым кольцом, справа решётка динамика и ручка.
Габариты ≈ **124 × 84 × 34 мм**.

```
 вид сверху                         разрез по диску
┌───────────────────────────┐      пластинка ▁▁▁▁▁▁▁▁▁▁▁  ← гнездо Ø50,6 гл. 1,2
│   ╭───────╮               │      дно гнезда 1,0 ══════
│  ╱ ╭─────╮ ╲    ::::::    │      PN532 (антенна вверх) ▭▭▭▭▭▭
│ │  │диск │  │   ::::::    │      рассеиватель ░░       ░░  ← кольцо света Ø60–68
│  ╲ ╰─────╯ ╱    ::::::    │      световой канал │       │
│   ╰───────╯        (◉)    │      кольцо WS2812  ▪▪       ▪▪  ← на 8 мм ниже
└───────────────────────────┘      ESP32, SD, провода
  свет вокруг   динамик ручка
```

### 7.1. Детали для печати

| Деталь | Пластик | Как печатать |
|---|---|---|
| Основание (поддон) со стойками под ESP32 и SD, вырезы USB-C и microSD | чёрный PLA | дном на стол, без поддержек |
| Верхняя панель: гнездо пластинки, кольцевая прорезь света, решётка динамика, отверстие ручки | чёрный PLA | лицом вверх, с разглаживанием верхнего слоя (ironing) |
| Рассеиватель — кольцо Ø60–68, толщина 1,0 мм | белый или натуральный PLA | плашмя |
| Световой стакан: держит кольцо WS2812 и PN532, не даёт свету уходить внутрь | белый PLA (отражает) | без поддержек |
| Ручка громкости | чёрный PLA | — |

Правила под ваш принтер: стенки 2,0 мм (5 линий), дно гнезда 1,0 мм (5 слоёв),
все посадки с зазором 0,15 мм на сторону, винты M3 вкручиваются прямо в пластик
(отверстие Ø2,6 мм), рассеиватель и стакан — на защёлку/трение, без клея.

### 7.2. Ключевые размеры

- Гнездо пластинки: Ø50,6 × 1,2 мм, сбоку вырез под палец.
- Расстояние метка → антенна PN532: ≈ 1,5–2 мм.
- Световое кольцо на панели: Ø60–68 мм. Между пластинкой и светом — чёрный ободок 4,7 мм.
  Светить вплотную к диску не получится: углы платы PN532 (диагональ 59 мм) перекрыли бы свет.
- От диодов до рассеивателя 8 мм — на этом расстоянии точки сливаются в сплошное кольцо.
- Динамик Ø40 смотрит вверх, от центра антенны не ближе 50 мм (магнит и стальная корзина мешают NFC).

Модели — параметрические (скрипт на Python, как генератор медальонов Findypet): диаметр и
толщина диска, размеры кольца и плат задаются числами в начале файла, на выходе STL и 3MF для Bambu Studio.

## 8. Обложки пластинок

Шаблон круглой наклейки Ø50 мм (поле под обрез 1 мм): «канавки» винила по краю, цветное
«яблоко» по центру с названием. Печать на самоклеящейся плёнке/бумаге, сверху по желанию
прозрачный ламинат. Металлизированную («зеркальную») плёнку не использовать — глушит NFC.

## 9. Порядок работ

1. **Проверка на столе, до печати корпуса.** Собрать на проводах ESP32 + PN532 + кольцо.
   Положить пластинку на PN532, кольцо — вокруг, как в корпусе. Убедиться, что UID читается
   стабильно при включённом кольце. Это главный риск проекта.
2. Добавить SD и усилитель, проверить звук и отсутствие щелчков при опросе метки.
3. Прошивка целиком: таблица меток, состояния, свет, ручка.
4. Замер реальных плат → генерация и печать корпуса.
5. Сборка, наклейки, заполнение `tags.csv`.

## 10. Риски и запасные ходы

| Риск | Что делаем |
|---|---|
| Медь кольца WS2812 ослабляет поле антенны, метка читается плохо | проверяется на шаге 1. Запасной ход — вместо готового кольца отрезок ленты WS2812B 144 диода/м, свёрнутый в стакане (лента не образует замкнутый виток) |
| Щелчки в динамике при опросе метки | разнести провода; опрос реже во время игры; экран не нужен |
| Размеры купленных плат отличаются от типовых | модели параметрические, печатаем после замера |
| Толщина пластинки больше 1,0 мм | один параметр глубины гнезда |

Аккумулятор (вторая версия): готовый модуль «зарядка + повышение до 5 В» с USB-C и
плоский Li-Po 2000 мА·ч под динамиком — около 4 часов работы. В первой версии только место под него.

## 11. Решения, принятые мной (поправьте, если не так)

- Питание только от USB-C, аккумулятор — позже.
- Управление одной ручкой-энкодером, без экрана.
- PN532 вместо RC522; готовое кольцо на 24 диода.
- Свет идёт кольцом вокруг пластинки с чёрным ободком, а не вплотную к ней.
- Динамик сверху справа, корпус — горизонтальная «вертушка», а не магнит на холодильник.
- Привязка «метка → музыка» в `tags.csv` на карте; цвет света задаётся там же.
