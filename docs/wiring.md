## Управление

- Пластинка на диске — играет её трек или папка; сняли — пауза; вернули ту же — продолжение.
- Поворот ручки — громкость (запоминается).
- Нажатие — пауза / продолжить. Двойное нажатие — следующий трек альбома.
- Долгое нажатие (около секунды) — переключение «вибродинамик / только AUX». В режиме AUX ручка светится синим.
- Подсветка ручки тёплая и становится ярче с громкостью.

Кабель Grove из комплекта модуля разрежьте пополам: разъём — в модуль, концы проводов — к ESP32.

## Карта памяти

FAT32, в корне файл `tags.csv` (образец — `firmware/sdcard/tags.csv`):

```
номер метки;путь к файлу или папке;цвет света RRGGBB
```

Незнакомая пластинка мигает красным, её номер дописывается в `/unknown.txt` — скопируйте его в `tags.csv`.
Номер также печатается в порт (115200 бод).

## Заливка прошивки

Нужен PlatformIO (расширение для VS Code или `pip install platformio`).

```
cd firmware
pio run -t upload
pio device monitor
```

Если свет бежит против часовой стрелки, поменяйте `RING_DIR` на `-1` в начале `firmware/src/main.cpp`.
Там же настраиваются яркость, число шагов громкости, предел усиления и `ENC_COUNTS_PER_STEP` —
сколько щелчков ручки даёт один шаг громкости.
