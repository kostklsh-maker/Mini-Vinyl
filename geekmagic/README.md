# GeekMagic SmallTV Ultra: свои картинки на экран с телефона

На видео — **GeekMagic SmallTV Ultra**, прошивка `Ultra-V9.0.54`, в сети по адресу `192.168.1.196`.
Здесь всё, чтобы в любой момент отправить на её экран любую картинку, GIF или текст:
с телефона (в том числе фоном, без открытия приложений), с ПК, из скрипта или по событию.

## Что это за устройство

| | |
|---|---|
| Чип | ESP8266 (модуль ESP-12F), 4 МБ флеша, под файлы ~3 МБ (свободно обычно ~0,9 МБ) |
| Экран | 1,54" IPS 240×240, контроллер ST7789, SPI без CS |
| Кнопка | одна, GPIO 4 |
| Питание | USB-C, 5 В |
| Пины (для своей прошивки) | MOSI 13, SCLK 14, DC 0, RST 2, подсветка 5 (ШИМ инвертирован: 0 = максимум), кнопка 4 |

**Про «открытый код» честно:** родная прошивка GeekMagic закрыта — на их GitHub лежат только
бинарники и инструкции. Зато у неё **открытое HTTP API без пароля**, которое сообщество полностью
разобрало, и есть открытые альтернативные прошивки. Для наших задач прошивать ничего не нужно:
всё ниже работает со стоковой прошивкой.

### HTTP API стоковой прошивки (Ultra-V9.x)

```
GET  /v.json                    {"m":"SmallTV-Ultra","v":"Ultra-V9.0.54"}
GET  /space.json                {"total":…, "free":…} байт
GET  /app.json                  {"theme":N}  (у новых часов 404, пока тему не меняли)
GET  /brt.json  /album.json  /timebrt.json  /city.json
POST /doUpload?dir=/image/      multipart, поле "file"; JPEG 240×240 baseline или GIF
GET  /set?theme=3               режим «Фотоальбом» (только в нём видно свою картинку)
GET  /set?img=/image/имя.jpg    показать файл
GET  /set?brt=0..100            яркость (до -10 — почти погасить)
GET  /set?autoplay=0&i_i=10     выключить слайд-шоу альбома
GET  /filelist?dir=/image/      список файлов (HTML)
GET  /delete?file=/image/имя    удалить файл
GET  /set?clear=image           удалить все картинки
GET  /set?reboot=1              перезагрузка
GET  /update                    страница обновления прошивки (сюда же грузят чужие прошивки)
```

Темы: 1 часы и погода, 2 прогноз, 3 фотоальбом, 4–6 стили часов, 7 простые часы с погодой.

Сводка взята из отчёта geekmagic-hacs по прошивке V9.0.40 и кода TokenTV; у вас V9.0.54 той же ветки.
На ваших часах я это не запускал — первый `python gmtv.py info` покажет, всё ли совпадает.

Нюансы, которые `gmtv.py` уже учитывает: картинку надо заранее ужать до 240×240 (родной веб-интерфейс
обрезает её в браузере), JPEG только baseline (не progressive), до ~60 КБ; на загрузку файл
отвечает «кривым» HTTP — это нормально; слайд-шоу альбома надо выключить, иначе оно перелистнёт
вашу картинку. Флеш изнашивается от частой записи, поэтому файл всегда один и тот же (`gmtv.jpg` /
`gmtv.gif`) — разумно обновлять не чаще раза в несколько секунд.

## Что в этой папке

| Файл | Что делает |
|---|---|
| `gmtv.py` | Один файл, нужен только Pillow. Библиотека + командная строка + мост с веб-страницей |
| `web/` | Страница для телефона: галерея, камера, буфер, текст, яркость, режимы; устанавливается как приложение и появляется в «Поделиться» |
| `termux/setup.sh` | Установка моста на Android-телефон с автозапуском в фоне |
| `tests/` | Тесты и `fake_device.py` — имитация часов, чтобы разрабатывать без них |

### Командная строка (ПК, Raspberry Pi, Termux)

```bash
pip install pillow
export GMTV_DEVICE=192.168.1.196        # Windows: set GMTV_DEVICE=192.168.1.196

python gmtv.py find                     # найти часы в сети, если IP поменялся
python gmtv.py info                     # прошивка, место, яркость, тема
python gmtv.py push photo.heic          # любое фото: обрежет до квадрата и покажет
python gmtv.py --fit fit push poster.png  # вписать целиком с полями
python gmtv.py push https://…/cat.gif   # GIF с анимацией, по ссылке
python gmtv.py text "Не беспокоить"     # текст максимального размера
python gmtv.py brightness 20
python gmtv.py theme 1                  # вернуть часы с погодой
python gmtv.py watch ~/Pictures/Screenshots   # каждый новый файл в папке — на экран
python gmtv.py serve                    # мост: http://<IP компьютера>:8240
```

### API моста (для Tasker, iOS «Команд», Home Assistant, своих скриптов)

```
POST /api/push[?fit=fill|fit]   тело — сам файл (любой формат) или multipart с полем file
POST /api/text                  JSON {"text":"…","fg":"#fff","bg":"#000"}  или  GET /api/text?text=…
GET  /api/brightness?value=40   GET /api/theme?value=1   GET /api/info   GET /api/last (что на экране)
```
Пароль: `serve --token СЕКРЕТ`, тогда заголовок `X-Token: СЕКРЕТ` или `?token=СЕКРЕТ`.

```bash
curl --data-binary @photo.jpg http://192.168.1.50:8240/api/push
curl "http://192.168.1.50:8240/api/text?text=Обед!"
```

## Как отправлять с телефона в фоне

### Android, полностью на телефоне (рекомендую)

Мост живёт прямо на телефоне в Termux и работает в фоне, ПК не нужен.

1. Установите из **F-Droid** приложения **Termux** и **Termux:Boot** (версии из Google Play устарели).
   Один раз откройте Termux:Boot.
2. В Termux: `pkg install git`, затем склонируйте этот репозиторий и запустите
   `bash ~/Mini-Vinyl/geekmagic/termux/setup.sh`. Скрипт сам найдёт часы, спросит,
   показывать ли новые скриншоты, и включит автозапуск.
3. В Chrome откройте `http://127.0.0.1:8240` → меню ⋮ → **«Установить приложение»**.
4. Настройки → Приложения → Termux → Батарея → **«Без ограничений»**.

Теперь: **Галерея → Поделиться → «Экран GeekMagic»** — картинка уходит на часы, ничего не открывая.
Если включили скриншоты — любой скриншот через пару секунд сам появляется на экране.
Из Tasker / MacroDroid / Automate — HTTP-запрос на `http://127.0.0.1:8240/api/...`
(уведомление пришло → текст на экран, будильник → картинка и т. д.).

### Android, мост на ПК или Raspberry Pi

Запустите `python gmtv.py serve` на компьютере, который всегда включён. На телефоне — приложение
**HTTP Shortcuts** (открытый код, F-Droid/Google Play): ярлык с методом POST на
`http://IP-компьютера:8240/api/push`, тело — «файл», включить «принимать файлы из Поделиться».
Страницу моста можно открыть с телефона, но в меню «Поделиться» она не встанет: браузер разрешает это
только для https или `127.0.0.1`.

### iPhone: «Команды», без моста

Создайте команду «На экран часов» (настройки команды: **Показывать в меню «Поделиться»**, тип — Изображения):

1. **Получить** изображения из меню «Поделиться» (если нет — «Выбрать фото»).
2. **Получить сведения об изображениях**: ширина и высота. **Если** ширина > высоты —
   **Обрезать изображение**: по центру, ширина = высота, высота = высота; **Иначе** — ширина = ширина, высота = ширина.
3. **Изменить размер изображения**: 240 × 240.
4. **Конвертировать изображение** в JPEG, качество ~0,8, без метаданных.
5. **Задать имя**: `phone.jpg`.
6. **Получить содержимое URL**: `http://192.168.1.196/doUpload?dir=/image/`, метод POST,
   тело «Форма», поле `file` типа «Файл» = результат шага 5.
7. **Получить содержимое URL**: `http://192.168.1.196/set?theme=3`
8. **Получить содержимое URL**: `http://192.168.1.196/set?img=/image/phone.jpg`

Один раз выключите слайд-шоу в веб-интерфейсе часов (раздел Album, Autoplay) или откройте
`http://192.168.1.196/set?autoplay=0&i_i=10`. При первом запуске iOS спросит доступ к локальной сети — разрешите.
Для автоматизаций («Автоматизация» в «Командах»): по NFC-метке, по включению фокуса «Работа»,
по приходу домой, по времени — тот же запрос `set?…` или текст через мост.
Если мост где-то запущен, всё проще: одна команда «Получить содержимое URL» POST на `/api/push`
с телом «Файл» — мост сам обрежет, сожмёт и поддержит HEIC и GIF.

Ограничение для всех вариантов: часы и телефон/мост должны быть **в одной сети Wi-Fi**.
Снаружи (мобильный интернет) — только через VPN домой (Tailscale/WireGuard) до моста.

## Идеи проектов

1. **Обложка пластинки для Mini-Vinyl.** Кладёте NFC-пластинку — на экране обложка альбома.
   Самый простой путь: в `tags.csv` добавить колонку с файлом обложки, а ESP32 после начала
   трека на пару секунд включает Wi-Fi и делает тот же `POST /doUpload` + `set?img=`
   (сейчас Wi-Fi в прошивке выключен ради чистого звука — включать только между треками).
   Путь богаче: голый модуль ST7789 240×240 прямо в стимпанк-корпусе вместо «манометра».
2. **Табличка статуса** у двери или на столе: «Не беспокоить», «Записываю», «На созвоне» —
   по фокусу на телефоне, по календарю, по NFC-метке на столе.
3. **Зеркало скриншотов**: сделали скриншот — он на экране (уже есть: `watch`).
4. **Уведомления**: курьер, такси, код из SMS, новый заказ — Tasker перехватывает уведомление
   и шлёт текст в `/api/text`.
5. **Счётчики бизнеса**: продажи за день, сканы NFC-жетонов Findypet, лиды — скрипт по расписанию
   рисует цифру и шлёт в `/api/push`.
6. **Статус ИИ-агентов**: [TokenTV](https://github.com/click6067-ship-it/token-tv) показывает лимиты
   Claude Code/Codex и пиксельных питомцев, реагирующих на работу агента.
7. **Умный дом**: [geekmagic-hacs](https://github.com/adrienbrault/geekmagic-hacs) для Home Assistant —
   дашборды с датчиками, погодой, камерами, без прошивки.
8. **Сейчас играет**: обложка трека со Spotify/YouTube Music (Tasker читает уведомление плеера,
   или скрипт на ПК через Spotify API).
9. **Своя прошивка**: [geekmagic-tv-esp8266](https://github.com/bvweerd/geekmagic-tv-esp8266) или ESPHome —
   кнопка, быстрые обновления без флеша, свои анимации. Первая прошивка только по UART
   (паять/цеплять к контактам), есть риск окирпичить; со стоком всё выше работает без этого.

## Разработка без часов

```bash
python tests/fake_device.py 8080 &          # имитация часов, «экран» на http://127.0.0.1:8080
python gmtv.py -d 127.0.0.1:8080 serve      # мост на http://127.0.0.1:8240
python -m unittest discover -s tests        # 15 тестов
```

Безопасность: у часов нет пароля, любой в вашей Wi-Fi может сменить картинку или залить прошивку.
Не выставляйте ни часы, ни мост в интернет напрямую.
